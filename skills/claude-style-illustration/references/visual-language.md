# Visual language

This project is an independent interpretation of Claude-inspired editorial illustration, not an official Anthropic specification. A concrete action makes an abstract idea approachable. Keep one focal relationship, generous space, irregular solid contours and three intended colors.

## Diagnose a result

- Uniform thin lines: ask for visibly swelling and narrowing marker gestures.
- Polished corporate icons: simplify detail and vary proportions, spacing and curves.
- Material collage or shading: restore flat solid color fields.
- Unclear metaphor: describe one object or one action, then remove unrelated marks.
- Raster palette drift: report it. Generated samples do not guarantee pixel-exact hex values.
